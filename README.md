# snek game :D

originally for snek ysws, but going to submit this to snowglobe instead
(Hack Club programs)

Main Idea:

user is a magical frog, you made a potion that went wrong, now the potion attacks you :D

Instructions:

use wasd to move
space to shoot
the potion shoots where the user is facing

More About the Game:

the potion chases the user
when potion takes a pause, it means it's going to dash at the user
after dashing, the potion goes left to right for a few seconds before it resumes chasing the user + repeating the dash and all
