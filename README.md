# snek game :D

originally for snek ysws, but going to submit this to snowglobe instead
(Hack Club programs)

Main Idea:

You're a magical frog, and you made a potion that went wrong, now it attacks you because it wants to steal your magic!

Info:

use wasd to move
space to shoot
user shoots where the user is facing

potion ceases after five hits
user ceases after three hits
potion hits user every 2 seconds

user flashes red when hit 
potion flashes red when hit

the potion chases the user
when potion takes a pause, it means it's going to dash at the user
after dashing, the potion goes left to right for a few seconds before it resumes chasing the user + repeating the dash and all
